# Daily Check-ins for user_bobbina

This folder will contain your daily check-in files for the 30-day wellness challenge.

Each day, you'll record:
- Whether you completed your yoga session
- Your energy level (1-10)
- Your stress level (1-10) 
- Any notes about how you're feeling
- Challenges you faced
- Wins and positive moments

Files will be named: day_01.md, day_02.md, etc.
